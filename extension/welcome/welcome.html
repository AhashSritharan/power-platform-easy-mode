Power Platform Toolbox

Developer tools for Dynamics 365, Power Platform, Jira & Clockify — right inside the pages you already work in.

🔒 Your data stays yours

  • No data collection. No analytics, no telemetry, no tracking, no accounts. Nothing is ever sent to us — there is no “us” server to send it to.
  • Everything runs locally. All processing happens inside your browser. Settings and tool data live only in your browser's local extension storage.
  • Network requests you can predict. The only requests made are the ones tools need for their job: your own Dynamics 365 / Power Platform environments, Jira, and — only if you configure a Clockify API key — the Clockify API. Requests to anything else are blocked by design.
  • Open source. Every line is auditable on GitHub.

🚀 Getting started

  1. Pin the extension — click the puzzle-piece icon in the toolbar and pin Power Platform Toolbox.
  2. Open a supported page — a Dynamics 365 app, make.powerapps.com, make.powerautomate.com, or Jira.
  3. Click the toolbox icon to see every tool command available on that page, or press Alt+Shift+P for the command palette.
