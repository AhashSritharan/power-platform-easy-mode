Power Platform Easy Mode

Developer tools for Dynamics 365, Power Platform, Jira & Clockify — right inside the pages you already work in. A few choices and you are ready.

    Choose your tools

    Everything Dynamics 365 and Power Platform is on; the Jira and Clockify integrations are off until you need them. You can change this any time in Settings.

    Floating launcher
    A small switch tab on the right edge of Dynamics 365 and Power Platform pages that opens the command palette.

    Your environments

    Label your environments DEV, TEST or PROD once: the label shows as a badge on every page of that environment, and the deploy, clone and flow tools offer them as targets. Easy Mode opens the Power Apps maker portal in a background tab to read the list of environments you can access, then closes it again.

    Clockify

    Entered once, used by both the Jira Clockify Timer and Clockify Sync. The key is stored only in this browser and sent only to api.clockify.me.

    You're all set 🎉

    1. Pin the extension — click the puzzle-piece icon in the toolbar and pin Power Platform Easy Mode.
    2. Open a supported page — a Dynamics 365 app, make.powerapps.com, make.powerautomate.com, or Jira.
    3. Click the Easy Mode icon to see every command available on that page, or press Alt+Shift+P for the command palette.

    Already have Dynamics or Power Platform tabs open? Reload them to start Easy Mode there. Everything you chose here can be changed later in , where you can also run this setup again.

    🔒 Your data stays yours

    • No data collection. No analytics, no telemetry, no tracking, no accounts. Nothing is ever sent to us — there is no “us” server to send it to.
    • Everything runs locally. All processing happens inside your browser. Settings and tool data live only in your browser's local extension storage.
    • Network requests you can predict. The only requests made are the ones tools need for their job: your own Dynamics 365 / Power Platform environments, Jira, and — only if you configure a Clockify API key — the Clockify API. Requests to anything else are blocked by design.
    • Open source. Every line is auditable on GitHub.
